# 项目总览

## 背景

当前项目已有 TypeScript + Express 服务，并能调用 DeepSeek 官方 OpenAI 兼容接口。下一阶段目标是把它扩展为一个本地论文改写工作台：用户选择 LaTeX 项目目录和报告 PDF，系统自动定位报告中疑似模板化、机械化、泛化表达对应的论文段落，完成受约束改写，更新 `.tex` 文件，并生成统计报告。

## 产品定位

系统不是“检测规避工具”，而是“学术表达质量修订工具”。它的目标是：

- 减少空泛、机械、模板化表达。
- 增强段落的具体性、上下文约束和真实研究语境。
- 保留论文事实、数据、引用和结论强度。
- 让每一次自动改写都可追踪、可回滚、可人工确认。

## 输入

- LaTeX 项目目录：包含 `.tex`、`.bib`、图片、模板、编译配置等。
- 报告 PDF：可能来自检测报告、导师批注、查重报告或人工审阅报告。
- 可选配置：
  - 目标语言：中文、英文、混合。
  - 修订范围：全文、章节、指定文件、指定页码、报告命中段落。
  - 修订强度：轻度润色、中度改写、保守学术重写。
  - 是否需要人工逐条确认。

## 输出

- 更新后的 LaTeX 文件。
- 修改前后的 diff。
- 统计报告：
  - 命中数量。
  - 按章节、文件、严重程度、问题类型统计。
  - 改写前后长度变化。
  - protected token 校验结果。
  - 编译结果。
  - 需要人工复核的风险项。
- 可下载归档包：修订后项目、报告、日志、JSON 任务记录。

## 核心原则

1. 不承诺任何检测器分数。
2. 不修改引用、公式、实验数据和结论强度。
3. 不新增未经用户提供的事实。
4. 自动改写默认走审计、分段、校验和报告闭环。
5. 高风险修改必须进入人工确认队列。
