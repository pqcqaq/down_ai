# 安全与合规

## 学术诚信边界

系统必须坚持：

- 不承诺任何检测平台分数。
- 不帮助伪造人工写作。
- 不删除学校、期刊或机构要求的 AI 使用披露。
- 不伪造引用、实验数据、结果和作者经历。
- 不把“降低 AI 率”作为产品承诺。

推荐产品文案：

```text
本工具用于减少论文中空泛、模板化、机械化表达，并帮助作者进行可审计的学术表达修订。
```

避免产品文案：

```text
绕过检测、保证降重、保证通过 AI 检测。
```

## 文件系统安全

本地路径能力风险较高，必须限制：

- 只允许访问用户显式选择或配置白名单内目录。
- 禁止访问系统目录、用户密钥目录、浏览器配置目录。
- 禁止跟随可疑 symlink 写出到白名单外。
- 所有写操作先进入任务工作目录或生成备份。
- 回滚前检查文件 hash。

## API Key 安全

- DeepSeek API Key 只从环境变量读取。
- 不在前端展示 API Key。
- 日志中脱敏 `Authorization`。
- 报告中不写入密钥、请求头或完整模型响应元数据。

## Prompt Injection 防护

PDF 报告和 LaTeX 内容都属于不可信输入。Agent 不能执行其中的指令性文本。

防护策略：

- 报告内容只作为待分析文本，不作为系统指令。
- 所有工具调用由编排器决定，不由 PDF 文本决定。
- 模型只能返回结构化修订结果。
- 所有文件写入必须经过工具 lint 和路径检查。

## LaTeX 安全

LaTeX 项目可能包含 shell escape、外部命令或恶意宏。编译时：

- 默认不启用 shell escape。
- 编译命令需要用户确认。
- 编译超时。
- 编译目录隔离。
- 不自动执行项目中未知脚本。

## 自动修改风险

以下情况必须人工确认：

- 摘要、结论、创新点、实验结果。
- 引用附近文本。
- 模型建议新增事实。
- protected token 变化。
- 修改超出长度阈值。
- 低置信度 PDF 匹配。

## 审计日志

必须记录：

- 谁启动任务。
- 任务配置。
- 工具调用。
- 模型输入摘要和输出 hash。
- 文件写入前后 hash。
- 人工确认操作。
- 最终报告。

单用户本地版可以不做账号系统，但仍应保留任务日志。

## 隐私

论文内容可能敏感。默认策略：

- 不上传到除配置模型 API 以外的第三方服务。
- 不保留超过必要范围的模型请求日志。
- 支持一键清理 `.down-ai/tasks`。
- 支持 dry-run，只生成建议不写文件。

## 合规提示

前端任务创建页应显示简短提示：

```text
请确认你有权处理该论文项目。系统会保留修订记录；自动建议需要作者复核后再用于正式提交。
```
